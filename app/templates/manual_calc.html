🔄 結果から続けて計算する

= を押して結果が出た後の操作には2つのパターンがあります。

📌 数字を押した場合

結果はクリアされ、新しい式の入力が始まります。
例：結果 100 → 5 を押す → 式 5 から開始

📌 演算子を押した場合

結果の値を使って計算が続きます。
例：結果 100 → + を押す → 100 + から続行

💡 パーセント (%) の使い方

% ボタンは数値の直後に押すと100分の1に変換します。以下のように使います。

入力例結果用途
1000 * 10%1001000 の 10% を計算
1000 + 1000 * 10%110010% 増しを計算
1000 - 1000 * 20%80020% 引きを計算
500%5500% = 5倍
💡 消費税の計算（税込・税抜）は「税計算」タブを使うほうが簡単で確実です。

メモリ機能

途中の値を一時保存して後で呼び出せます。複数の小計を積み上げるような計算に便利です。

💾 メモリボタンの機能

通常モードのキーパッド上部に4つのメモリボタンがあります。現在のメモリ値はヘッダーの「MEMORY」欄に常時表示されます。

ボタン機能使い方の例
MC Memory Clear — メモリを 0 にリセットします 計算をリセットして最初からやり直すとき
MR Memory Recall — 保存している値を式に入力します 保存した小計を別の計算に使いたいとき
M− Memory Subtract — 現在の入力値をメモリから引きます 複数の出費をメモリから差し引きするとき
M+ Memory Add — 現在の入力値をメモリに足します 複数の小計をメモリに積み上げていくとき
📖 メモリの使用例

複数の項目の合計を別々に計算してから積み上げる例：

操作メモリの値説明
MC を押す0まずメモリをクリア
1200 + 800 = → M+2,000A商品の小計 2,000 をメモリに加算
500 * 3 = → M+3,500B商品の小計 1,500 をメモリに追加
300 = → M−3,200割引 300 をメモリから減算
MR を押す3,200最終合計 3,200 を式に入力
ℹ️ M+ / M− を押したとき、= 押下後の結果がある場合はその結果値が、式入力中の場合は現在の式の値がメモリに加減算されます。
🧾

税計算

金額と税率を入力するだけで「税込金額」「税抜金額」「税額」を瞬時に計算します。8%・10%・カスタム税率に対応しています。

1
金額と税率を入力する

「金額」欄に計算したい金額を入力します。「税率」欄で10%・8%・カスタムを選択します。カスタムを選ぶと任意の税率を入力できます。

💡 カスタム税率は入力した値が自動で保存され、次回開いたときに引き継がれます。
2
「税込」または「税抜」ボタンを押す

計算したい方向に合わせてボタンを選びます。

🧾 税込ボタン

税抜の金額から → 税込合計を求めます

例：本体 1,000円 + 税10%
→ 税額 100円、税込 1,100円

🧾 税抜ボタン

税込の金額から → 税抜本体を求めます

例：税込 1,100円 → 税10%
→ 本体 1,000円、税額 100円

📊 結果の見方
税込: 1,100円 税額: 100円 本体: 1,000円
項目内容
税込税を含めた合計金額（円）
税額消費税の金額（円）。端数は四捨五入されます
本体税を除いた本体金額（円）
ℹ️ 税額の端数処理：「税込」計算では Math.round(本体 × 税率 ÷ 100)、「税抜」計算では Math.round(税込 ÷ (1 + 税率 ÷ 100)) で計算されます。
⏰

時間計算

「HH:MM」形式で時間を入力し、加減算・乗除算ができます。労働時間の合計や残業時間の計算などに使えます。

1
時間式を入力する

「時間式」欄に計算したい時間の式を入力します。時間は 時間:分 の形式（例：1:30）で入力します。

入力例内容
1:30 + 0:451時間30分 + 45分 = 2時間15分
8:00 - 1:308時間 − 1時間30分 = 6時間30分
0:30 * 430分 × 4 = 2時間（整数の乗算も可）
9:00 - 12:30マイナスの場合は「-3:30」のように符号付きで表示
8:00 + 8:00 + 9:003つ以上を足すことも可能
⚠️ 時間値は必ず HH:MM または H:MM の形式で入力してください。:MM は 00〜59 の範囲です。整数（例：3）を時間として使うことはできません。
2
時間入力パッドを使う

画面に表示される数字パッドで入力することもできます。テキスト欄に直接キーボードで打ち込んでもかまいません。

パッドのボタン機能
数字 0〜9数字を入力します
:コロン（時間と分の区切り）を入力します
00「00」を入力します。分の入力を素早く行えます
+・−加算・減算の演算子を入力します
⌫（←）入力欄のカーソル前の1文字を削除します
AC時間式の入力をすべてクリアします
=時間式を計算して結果を表示します
コピー結果の時間（HH:MM形式）をコピーします
📊 結果の見方
2:15 135分
項目内容
1行目（HH:MM）計算結果を時間:分の形式で表示します。24時間を超えても時間部分がそのまま増加します（例：25:30）
2行目（○分）計算結果を分単位の整数で表示します
💡 「コピー」ボタンで HH:MM 形式の1行目だけがクリップボードにコピーされます。
📝

履歴

通常・税計算・時間計算のすべての計算結果が自動的に履歴に記録されます。最大50件保存でき、再利用・コピー・削除が可能です。

📋 履歴に記録される内容
モード履歴のサマリー例
通常1200+300*2 = 1,800
税計算税込 1,100円
時間計算1:30+0:45 = 2:15

各履歴には計算日時も表示されます。

⚙️ 履歴の操作
ボタン機能
再利用 その計算の入力状態を復元します。
・通常モード：式と結果を復元します
・時間計算モード：時間式を復元します
・税計算モード：税計算タブに切り替わります（値は復元されません）
コピー その計算の結果をクリップボードにコピーします
削除 その履歴項目を一覧から削除します
全消去 履歴パネル右上の「全消去」ボタンですべての履歴を一括削除します
ℹ️ 履歴はブラウザの localStorage に保存されます。同じブラウザ・同じデバイスのみで共有されます。ブラウザのデータをクリアすると履歴も消えます。最大50件を超えると古いものから自動削除されます。
⌨️

キーボードショートカット

通常モードではキーボードで全操作が可能です。他の入力欄（テキストボックスなど）にフォーカスがない状態で有効です。

⌨️ 通常モードのキーボード操作
キー機能
0 〜 9数字を入力します
.小数点を入力します
+加算演算子を入力します
-減算演算子を入力します（先頭で押すと負の数の入力になります）
*乗算演算子を入力します
/除算演算子を入力します
(左かっこを入力します
)右かっこを入力します
%パーセントを入力します
Enter計算を実行します（= ボタンと同じ）
Backspace末尾の1文字を削除します（← ボタンと同じ）
Esc入力をすべてクリアします（AC ボタンと同じ）
ℹ️ 税計算や時間計算のタブに切り替えているとき、または他の入力フィールドにフォーカスがある場合は、キーボードショートカットは無効になります。
