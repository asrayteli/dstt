📘 DaiShinToTools 使い方マニュアル

このページでは、DaiShinToTools（DSTT）で利用できる主な機能と、基本的な使い方をまとめています。 画面左のサイドバー、またはダッシュボードから各機能へ移動できます。

基本操作

ログイン → ツール選択 → ファイルまたは条件を入力 → 実行

推奨ブラウザ

Google Chrome / Microsoft Edge 最新版

注意

個人情報を含むデータの取り扱いにご注意ください

🚀 主な機能一覧

📆 日時計算

日時の加算・減算・差分を計算します。

🧮 電卓

シンプルな四則演算が行えます。

🔄 一括リネーム / 📦 ファイル圧縮

ファイル名変更やZIP化をまとめて処理します。

📊 PowerCSV / 📚 PowerPDF

CSV・PDFの編集や変換を支援します。

📪️ FILE POST

ファイル共有用のアップロード・ダウンロード機能です。

👥 ShifterSync / ⛵ 有休共有

シフト作成や休暇情報共有を効率化します。

📝 月次ジェネレーター / ⚖️ SAT

報告書作成や科目別分析を支援します。

📛 社員名簿PLUS

社員情報の検索・表示を高速に行えます。

🛠 基本的な使い方

  1. ログイン後、ダッシュボードまたはサイドバーから使いたいツールを選択します。
  2. 必要な入力値（日時・数値・ファイルなど）を設定します。
  3. 実行ボタンを押して処理し、結果を確認・ダウンロードします。
  4. 別作業を行う場合は、左側のメニューから他の機能へ切り替えます。

❓ よくある質問

Q. 画面が表示されない・動作が遅い場合は？

A. ブラウザの再読み込み、または再ログインをお試しください。

Q. アップロードに失敗する場合は？

A. ファイル形式・サイズ・ネットワーク接続をご確認ください。

Q. 管理者向け機能が見えない場合は？

A. 管理者権限ユーザーでログインしているかご確認ください。
