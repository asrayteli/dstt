FILE COMPRESS MANUAL

ファイル圧縮ツール マニュアル

複数のファイルやフォルダを ZIP / TAR 系形式にまとめてダウンロードできるツールです。
除外条件・パスワード・フォルダ構造など、あらゆる設定を確認しながら出力できます。

概要 ファイルの選び方 圧縮形式 詳細設定 プリセット・履歴 プレビューと出力 FAQ
1

概要

📦

5つの形式

ZIP・TAR・TAR.GZ・TAR.BZ2・TAR.XZ から用途に合った形式で出力できます。

🔐

ZIP パスワード

ZIP形式にはAES-256暗号化パスワードを設定できます。

🗂️

フォルダ選択

ファイル単体だけでなくフォルダごとドロップして、階層構造を保ったまま圧縮できます。

🚫

除外フィルター

拡張子やワイルドカードパターンで不要ファイルを自動的に除外できます。

👁️

リアルタイムプレビュー

設定を変えるたびに格納ファイル一覧と出力ファイル名がリアルタイムで更新されます。

⚡

プリセット・履歴

よく使う設定をプリセットまたは自動保存される履歴からワンクリックで呼び出せます。

2

ファイルの選び方

A
ドロップゾーンへドラッグ

ファイルやフォルダを画面中央のドロップ枠（点線の枠）へドラッグ＆ドロップします。複数ファイルを一度にドロップできます。フォルダをドロップするとフォルダ内のファイルが全て追加され、サブフォルダの階層構造もそのまま保持されます。

B
クリックしてファイルを選択

ドロップ枠をクリックするとファイル選択ダイアログが開きます。複数ファイルを選んでまとめて追加できます。

C
「フォルダを選択」ボタン

ドロップ枠の下にある「フォルダを選択」ボタンをクリックすると、フォルダ選択ダイアログが開きます。フォルダ内のすべてのファイルが再帰的に追加され、フォルダの階層構造が保持されます。

💡
ファイルを追加すると「ファイル詳細」テーブルに一覧が表示されます。削除したいファイルは各行の「削除」ボタンで個別に外せます。全部やり直したいときは「設定をリセット」ボタンを使います。

格納名 / 除外理由 対象 の場合は圧縮ファイル内での保存パスが表示されます。

3

圧縮形式

画面右側の「圧縮形式」ボタンから選びます。選択中の形式がハイライトされます。

形式 特徴 パスワード おすすめ用途
ZIP 最も汎用性が高く、Windows / Mac / Linux で標準対応。AES-256 暗号化パスワード設定可能。 使用可 一般的なファイル共有、パスワード付き配布
TAR ファイルをまとめるだけで圧縮は行わない。ファイルサイズはほぼ変わらない。 使用不可 Linux/Unix 環境でのバックアップ、圧縮なしのまとめ
TAR.GZ TAR + gzip 圧縮。ZIP より若干圧縮率が高く、Linux で広く使われる。 使用不可 Linux 向けの配布、圧縮率重視の用途
TAR.BZ2 TAR + bzip2 圧縮。gzip より圧縮率が高いが処理に時間がかかる。 使用不可 圧縮率を最優先し、時間を許容できる場合
TAR.XZ TAR + xz 圧縮。最も高い圧縮率を持つが、処理時間が長い。 使用不可 最高圧縮率が必要なアーカイブ
⚠️
パスワード保護を使いたい場合は ZIP 形式を選択 してください。TAR 系形式ではパスワード欄が無効になります。
💡
迷ったときは ZIP（標準） を使うのがおすすめです。Windows・Mac どちらでも標準で開け、パスワードも設定できます。
4

詳細設定

「詳細設定」エリアの各入力欄の説明です。設定を変えるたびにプレビューが自動更新されます。

出力ファイル名 任意
ダウンロードされる圧縮ファイルの名前（拡張子なし）を入力します。
空欄の場合は dstt_compressed になります。
例: 2026_配布資料 → 2026_配布資料.zip
圧縮ファイル内のフォルダ名 任意
圧縮ファイルを開いたときに、この名前のフォルダの中に全ファイルをまとめます。
空欄の場合、ファイルはフォルダなしで直接入ります。
例: 配布用データ と入れると、配布用データ/ファイル名.ext という形で格納されます。
圧縮レベル
標準（デフォルト）: 圧縮率と速度のバランスが取れた設定です。
高圧縮: ファイルサイズをより小さくしますが、処理に時間がかかります。
TAR.XZ 形式では圧縮レベルの設定は無効です。
パスワード ZIP のみ
ZIP 形式選択時のみ有効です。入力するとAES-256暗号化が適用されます。
「表示」ボタンでパスワードの表示・非表示を切り替えられます。
パスワードはサーバーに保存されません。受け取る相手にパスワードを別途伝えてください。
除外拡張子 任意
指定した拡張子のファイルを圧縮対象から除外します。カンマ区切りで複数指定可。
例: log,tmp,bak
ドット（.）あり・なしどちらでも可: .log と log は同じ意味です。
除外パターン 任意
ワイルドカード（*）を使ってファイル名や相対パス全体でフィルタリングします。カンマ区切りで複数指定可。
例: *.tmp、*_old.*、backup/*
大文字・小文字の区別はありません。
除外フィルターの例
設定 値 除外されるファイル例
除外拡張子 log,tmp debug.log、work.tmp、app.log
除外パターン *.bak data.bak、config.bak
除外パターン *_old.* report_old.xlsx、data_old.csv
除外パターン backup/* backup/ フォルダ内の全ファイル
両方組み合わせ 除外拡張子: log
除外パターン: *.tmp,*_old.*		 上記すべてのファイルが除外
ℹ️
同じ名前のファイルが複数ある場合は、自動的に ファイル名 (1).ext、ファイル名 (2).ext のように連番が付きます。これを「重複リネーム」と呼び、メトリクスに件数が表示されます。

プリセット・履歴

設定プリセット

よく使う設定の組み合わせをワンクリックで呼び出せます。

📦 標準ZIP

  • 形式: ZIP
  • 圧縮レベル: 標準
  • 除外・パスワードなし

🔐 パスワード付きZIP

  • 形式: ZIP
  • 圧縮レベル: 高圧縮
  • パスワード欄にフォーカス
  • （パスワードは自分で入力）

🧹 ログ除外

  • 形式: ZIP / 標準
  • 除外拡張子: log, tmp, bak
  • 除外パターン: *_old.*

📁 配布用フォルダあり

  • 形式: ZIP / 標準
  • 格納フォルダ: 配布用データ
  • 解凍後にフォルダへまとまる
💡
「パスワード付きZIP」プリセットはパスワード欄にカーソルが移動するだけで、パスワード自体は自動入力されません。必ず自分でパスワードを入力してください。

設定履歴

「圧縮してダウンロード」や各設定変更のたびに、現在の設定が履歴として自動保存されます（ブラウザの localStorage に最大10件）。

履歴の仕組み
操作 内容
履歴ボタンをクリック その設定（形式・ファイル名・除外条件など）を一括で復元します。ファイルの選択は復元されません。
保存タイミング 形式変更・設定変更・ダウンロードのたびに自動保存されます。
ラベル 出力ファイル名を入力しているときはその名前、未入力の場合は形式名（例: ZIP 設定）が表示されます。
最大件数 最大10件。超えた場合は古いものから自動削除されます。同じ設定は重複保存されません。

プレビューと出力

プレビューボックスの見方

画面右側の「プレビュー」エリアで、生成されるファイル名と警告を確認できます。

生成予定ファイル
2026_配布資料.zip

プレビューに警告（黄色テキスト）が表示された場合は、設定を見直してください。例えば「対象ファイルがありません」という警告が出た場合は、除外設定が厳しすぎてすべてのファイルが除外されています。

主な警告メッセージ
警告メッセージ 原因と対処法
対象ファイルがありません。 除外設定によりすべてのファイルが除外されています。除外拡張子・除外パターンを緩めてください。
一度に処理できるファイル数は500件までです。 選択ファイル数が500件を超えています。ファイルを減らして複数回に分けてください。
合計サイズは〇〇MBまでです。 合計ファイルサイズが1GBを超えています。ファイルを分けて別々に圧縮してください。

ダウンロードと設定リセット

1
圧縮してダウンロード

「圧縮してダウンロード」ボタンを押すと、サーバー側で圧縮処理が行われ、完了後に自動的にファイルがダウンロードされます。大きなファイルや多数のファイルがある場合は処理に時間がかかる場合があります。

2
設定をリセット

「設定をリセット」ボタンを押すと、選択したファイル・すべての設定・パスワードが初期状態（ZIP・標準）に戻ります。最初からやり直したいときに使います。

✅
ダウンロードされるファイル名は「プレビュー」に表示されているファイル名（例: 2026_配布資料.zip）と同じです。ダウンロード前に必ず確認してください。
7

よくある質問

迷ったときは ZIP を選んでください。Windows・Mac・Linux どの環境でも標準で対応しており、パスワード保護も設定できます。Linux や開発環境向けには TAR.GZ が一般的です。TAR.BZ2・TAR.XZ は圧縮率を最大化したい場合に使いますが、処理時間がかかります。
次の点を確認してください。①圧縮形式が ZIP になっているか（TAR系ではパスワードが無効です）。②パスワードを正確に共有しているか。③受け取り側の解凍ソフトが ZIP のパスワード（AES-256）に対応しているか。Windows 標準の解凍機能は古い場合に AES-256 に非対応のことがあります。7-Zip などの対応ソフトをお試しください。
「フォルダを選択」ボタンか、ドロップ枠にフォルダをドラッグすることで対応できます。フォルダ内のサブフォルダも含め、階層構造を保ったまま圧縮ファイルに追加されます。なお、圧縮ファイル内でのフォルダ名を変えたい場合は「圧縮ファイル内のフォルダ名」欄に名前を入れてください。
除外拡張子または除外パターンの設定が厳しすぎて、すべてのファイルが除外されています。除外設定の欄を確認し、不要な条件を削除または修正してください。また、ファイルをまったく追加していない場合も同じメッセージが表示されます。
2件目以降は自動的に ファイル名 (1).ext、ファイル名 (2).ext のように連番が付きます。どのファイルに連番が付いたかはファイル詳細テーブルの「格納名」列で確認できます。また、「重複リネーム」メトリクスに件数が表示されます。
除外拡張子は拡張子だけで判定します（例: log と入れると .log 拡張子のファイルをすべて除外）。除外パターンはファイル名全体または相対パスに対してワイルドカード（*）でマッチングします（例: *_old.* は data_old.csv を除外）。両方を組み合わせて使うこともできます。
TAR はファイルをひとつにまとめるだけで、圧縮は行いません。そのため、ファイルサイズはほぼ元のままです。TAR.GZ は TAR でまとめたあとに gzip で圧縮を行います。テキストファイルや CSS・JS などは大幅に小さくなりますが、すでに圧縮済みの画像や動画はほとんど効果がありません。
形式の選択・各設定の変更・ダウンロードボタンの押下のタイミングで自動保存されます。保存場所はお使いのブラウザの localStorage です。最大10件まで保存され、同じ設定は重複して保存されません。ブラウザのデータを削除すると履歴も消えます。
1回の処理で扱えるファイル数は最大500件です。500件を超える場合は、ファイルをいくつかのグループに分けて、それぞれ別々に圧縮ファイルを作成してください。合計サイズの上限（1 GB）も同様です。
次を確認してください。①パスワードを設定した ZIP の場合、パスワードが相手に正確に届いているか。②受け取り側の OS や解凍ソフトが対応しているか（TAR 系は Windows で標準対応していない場合があります。7-Zip などをご利用ください）。③ファイルが途中でダウンロードが止まっていないか（ファイルが壊れている場合は再ダウンロードをお試しください）。
