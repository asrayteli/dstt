基本の流れ

3ステップでファイル名を一括変換できます。

1
ファイルを選択する

画面中央の破線枠エリアにファイルをドラッグ＆ドロップするか、枠をクリックして選択ダイアログを開きます。複数ファイルを一度に追加できます。

ドラッグ＆ドロップ
  • ファイルをブラウザ外からドラッグして枠内に置きます
  • 枠がハイライトされたらドロップできます
クリックして選択
  • 枠か「クリックして選択」リンクをクリック
  • Ctrl（Mac: ⌘）を押しながら選択で複数指定可
  • 追加されたファイルは枠の下にチップ（タグ）形式で一覧表示されます
  • 各チップの「×」ボタンで個別削除、「全クリア」ボタンで全ファイルを削除できます
  • ファイル形式・サイズの制限はありません（どんな種類のファイルでも可）
2
変換モードを選んで設定する

10種類の変換モードから目的に合ったものをクリックして選択します。選択すると専用の設定項目が表示されます。設定を変えるたびに下のプレビューがリアルタイムで更新されます。

💡 モードを選ぶと画面にそのモードの説明と変換例が表示されます。どんな変換になるか迷ったときは説明を参考にしてください。
3
プレビューを確認して変換＆ダウンロード

プレビュー表の「変更前」→「変更後」を確認し、思い通りになっていれば「変換＆ダウンロード」ボタンを押します。変換後のファイルが入ったZIPファイルがダウンロードされます。

ℹ️ ダウンロードされるファイル名は「リネーム済みファイル.zip」です。ZIPを展開すると変換後の名前のファイルが入っています。
🔢

変換モード一覧

10種類の変換モードそれぞれの機能と設定内容を解説します。

🔢 連番

元のファイル名を無視し、指定した接頭語と連番で統一的にリネームします。大量のファイルに通し番号を振るときに便利です。

設定項目
接頭語（prefix）ファイル名の先頭に付ける文字列です。デフォルト: file_
例：接頭語 report_ → 報告書.pdf, メモ.docx → report_001.pdf, report_002.docx
💡 開始番号やゼロ埋め桁数は「共通オプション」で変更できます。
📅 日付＋連番

今日の日付と連番を組み合わせてリネームします。日報・議事録・日次ファイルなど日付管理したいファイルに最適です。

設定項目（このモード固有の設定はなし）

日付フォーマットと開始番号・桁数は「共通オプション」で変更できます。

例：報告書.pdf → 20260520_001.pdf（今日が 2026-05-20 の場合）
🔤 文字列置換

ファイル名の中の特定の文字列を別の文字列に置き換えます。ファイル名の一部だけを統一したいときに使います。

設定項目
置換元（探す文字列）ファイル名から見つける文字列。該当しないファイルは変更されません。
置換先（変える文字列）見つかった部分を置き換える文字列。空欄にすると削除になります。
例：「old」→「new」 : report_old.pdf → report_new.pdf
例：「IMG_」→「」（空欄）: IMG_0001.jpg → 0001.jpg
ℹ️ 置換元に何も入力しないと、ファイル名は変更されません。拡張子も含む全ファイル名（例：report.pdf）が対象です。
🔍 正規表現

正規表現パターンを使った高度な文字列置換を行います。括弧でグループ化した部分は \1・\2 で参照できます（Pythonの re.sub 互換）。

設定項目
正規表現パターンマッチする文字列パターンを正規表現で記述します
置換文字列マッチした部分の置換後を記述します。\1〜\9 でグループ参照可
例：パターン (\d{4})(\d{2})(\d{2}) → 置換 \1-\2-\3
  file_20260520.txt → file_2026-05-20.txt
⚠️ 正規表現が無効（構文エラー）な場合、そのファイルは変換されず元のファイル名のままになります。
➕ 元名＋連番

元のファイル名を残したまま、末尾（拡張子の前）に連番を付加します。バージョン管理や重複ファイルの整理に使えます。

設定項目なし（共通オプションで開始番号・桁数を変更できます）

例：design.png, logo.png → design_001.png, logo_002.png
📆 元名＋日付

元のファイル名を残したまま、末尾に今日の日付を付加します。バックアップや日次スナップショットの命名に便利です。

設定項目なし（共通オプションで日付フォーマットを変更できます）

例：data.csv → data_20260520.csv
Aa 大文字/小文字変換

ファイル名の大文字・小文字を変換します。拡張子のみを統一する専用オプションも用意されています。

変換タイプ
全て小文字ファイル名と拡張子の両方を小文字にします
例：My_REPORT.PDF → my_report.pdf
全て大文字ファイル名と拡張子の両方を大文字にします
例：my_report.pdf → MY_REPORT.PDF
タイトルケースアンダースコアとハイフンを区切りとして、各単語の先頭を大文字にします
例：my_report_2026.pdf → My_Report_2026.pdf
拡張子のみ小文字ファイル名部分はそのまま、拡張子だけ小文字に変換します
例：Photo.JPG → Photo.jpg
拡張子のみ大文字ファイル名部分はそのまま、拡張子だけ大文字に変換します
例：photo.jpg → photo.JPG
📝 挿入

ファイル名の指定した位置（拡張子は含まない部分）にテキストを挿入します。

設定項目
挿入位置先頭から何文字目に挿入するかを数値で指定します。
0 = 先頭、正の数 = 先頭から数えた位置、負の数 = 末尾から数えた位置（例：-1 は末尾1文字手前）
挿入するテキスト挿入する文字列を入力します。例：v2_、_backup
例：位置=0, テキスト「v2_」 : report.pdf → v2_report.pdf
例：位置=6, テキスト「_v2」 : report.pdf → report_v2.pdf
✂️ 削除

ファイル名の指定した位置から指定した文字数を削除します（拡張子は除く部分のみ対象）。不要なプレフィックスやコード番号の除去に使えます。

設定項目
開始位置削除を始める位置（先頭から0始まり）。0 = 先頭の文字から削除。
削除文字数削除する文字の数。0 の場合は何も削除しません。
例：開始=0, 削除=4 : IMG_sunset.jpg → sunset.jpg（先頭の「IMG_」4文字を削除）
例：開始=3, 削除=2 : abcXXdef.txt → abcdef.txt（4文字目から「XX」2文字を削除）
🛠️ カスタムパターン

トークン（変数）を自由に組み合わせて、オリジナルの命名ルールを作れます。詳しくは「カスタムパターン」セクションをご覧ください。

例：パターン {date}_{name}_{num}{ext} → 20260520_report_001.pdf
🛠️

カスタムパターン

8種類のトークン（変数）を組み合わせて、完全に自由なファイル命名ルールを作れます。トークンチップをクリックするとパターン欄に直接挿入できます。

📌 使用できるトークン一覧

ファイル名が Report_2025.pdf の場合の変換例を示します。

トークン説明変換例
{name} 拡張子を除いたファイル名 Report_2025
{ext} 拡張子（ドット付き） .pdf
{num} ゼロ埋め連番（共通オプションで桁数変更可） 001, 002, 003...
{date} 今日の日付（共通オプションでフォーマット変更可） 20260520
{original} 元のファイル名（拡張子込み） Report_2025.pdf
{upper} 拡張子を除いたファイル名を大文字化 REPORT_2025
{lower} 拡張子を除いたファイル名を小文字化 report_2025
{i} 0始まりの連番インデックス（ゼロ埋めなし） 0, 1, 2...
💡 パターンの使用例
パターン変換例（元: report.pdf, 2枚目）説明
{name}{ext} report.pdf 変更なし（デフォルト）
{date}_{name}_{num}{ext} 20260520_report_002.pdf 日付＋名前＋連番
{lower}_{num}{ext} report_002.pdf 小文字化＋連番
backup_{date}_{original} backup_20260520_report.pdf バックアップ用プレフィックス
{i}_{name}{ext} 1_report.pdf 0始まりインデックス
💡 カスタムパターン入力欄の上にあるトークンチップ（青いボタン）をクリックすると、カーソル位置にトークンを自動挿入できます。
ℹ️ 未定義のトークン（例：{abc}）はパターンから自動で除去されます。
⚙️

共通オプション

すべてのモードに影響する共通設定です。「共通オプション」をクリックして展開して設定します。

⚙️ 共通オプションの設定項目
項目デフォルト値説明
開始番号 1 連番の最初の数値を指定します。例：5 にすると 005, 006... と始まります。0 を指定すると 000, 001... となります。
ゼロ埋め桁数 3 連番を何桁でゼロ埋めするかを指定します。例：3 → 001, 4 → 0001。1〜10 の範囲で設定できます。
日付フォーマット %Y%m%d 日付の表示形式をPythonのstrftime形式で指定します。よく使う形式は右の一覧を参照してください。
よく使う日付フォーマット
フォーマット表示例（2026年5月20日）
%Y%m%d20260520（デフォルト）
%Y-%m-%d2026-05-20
%Y/%m/%d2026/05/20
%Y%m202605（年月のみ）
%m%d0520（月日のみ）

よくある質問

使い方で迷ったときはこちらを確認してください。

特定の上限は設定されていませんが、大量のファイル（数百件以上）や大容量ファイルを一度に処理するとブラウザやサーバーに負荷がかかる場合があります。プレビューは何ファイルでも表示できますが、ダウンロード時は数十件ずつ分けて処理することをおすすめします。

ZIP内でファイル名が重複した場合、後から追加されたファイルの名前に番号が自動付加されます。プレビューで事前に重複がないか確認してください。
ファイルが1件も追加されていない場合はボタンが無効になります。最低1つのファイルを追加してください。ファイルを追加すると自動的にボタンが有効になります。
その文字列が含まれないファイルは変更されず、元のファイル名のままダウンロードされます。プレビューでは「=」マークで変更なしと表示されます。
Python の re.sub に対応した正規表現が使えます。グループ参照は \1〜\9 で行います。ただし後読み・先読みなどの複雑な構文は正しく動作しない場合があります。プレビューで必ず確認してください。パターンが無効な場合、そのファイルは変換されません。
拡張子を除いたファイル名を対象に、先頭を0として数えます。例えば「report」というファイル名なら、0=先頭（r の前）、6=末尾（t の後）です。-1 は末尾の1文字手前（t の前）を意味します。プレビューで確認しながら調整してください。
{ext} は拡張子がない場合は空文字列になります。{name} はファイル名全体になります。プレビューで確認してから処理してください。

🔍 正規表現モードの例

パターン置換文字列変換例
(\d{4})(\d{2})(\d{2}) \1-\2-\3 file_20260520.txt → file_2026-05-20.txt
^IMG_ （空欄） IMG_001.jpg → 001.jpg（先頭のIMG_を削除）
_v\d+ （空欄） report_v2.pdf → report.pdf（バージョン番号を削除）
\s+ _ my file name.txt → my_file_name.txt（スペースをアンダースコアに）
(\w+)_(\w+) \2_\1 first_second.txt → second_first.txt（2つの単語を入れ替え）
⚠️ 正規表現が無効な場合、そのファイルは変換されません。プレビューで必ず確認してください。
