DSTT 完全マニュアル

DaiShinTo Tools - 業務効率化ツール集

🔍

🏠 概要

DSTT (DaiShinTo Tools) は、日常業務を効率化するためのWebベースツール集です。

主な特徴

  • 📱 ブラウザベース - インストール不要、どの端末からでもアクセス可能
  • 🔐 セキュア - ユーザー認証システムで安全にアクセス
  • 🌐 レスポンシブ - PC・タブレット・スマートフォン対応
  • 🇯🇵 日本語完全対応 - UI・ファイル処理ともに日本語対応
  • ⚡ 高速処理 - 最適化されたアルゴリズムで快適な動作
💡 使用前の準備

初回利用時は管理者からユーザーIDとパスワードの発行を受けてください。

🚀 はじめに

ログイン手順

  1. ブラウザでDSTTのURLにアクセス
  2. 管理者から発行されたユーザーIDとパスワードを入力
  3. 「ログイン」ボタンをクリック
  4. ダッシュボードが表示されれば完了

基本的な操作

  • 左サイドバーまたはダッシュボードから使いたいツールを選択
  • 各ツールの画面で必要な操作を実行
  • 結果ファイルは自動でダウンロードされます
  • ログアウトは画面右上のメニューから

🛠️ ツール一覧

📆
日時計算ツール
日時の加算・減算や、2つの日時間の差分を計算できます。

使い方

  1. 基準日時を入力（日時加算・減算の場合）
  2. 加算・減算したい日数、時間、分を入力
  3. 「加算」または「減算」を選択
  4. 「計算」ボタンをクリックして結果を確認

日時差分の計算

  1. 比較したい2つの日時をそれぞれ入力
  2. 「差分計算」ボタンをクリック
  3. 日数・時間・分の差分が表示されます
💡 活用例

プロジェクトの納期計算、シフトの時間計算、作業時間の算出など。

🧮
電卓
ブラウザ上で動作するシンプルな電卓です。

使い方

  1. 画面のボタンをクリックして数式を入力
  2. 「Enter」ボタンまたはキーボードのEnterキーで計算実行
  3. 「C」ボタンで表示をクリア
  4. 計算履歴は画面下部に自動保存されます

対応する計算

  • 四則演算（+、-、×、÷）
  • 括弧を使った計算
  • 小数点計算
⌨️ キーボードショートカット

数字キー、演算子キー、Enter（計算実行）、Escape（クリア）、Backspace（一文字削除）

ファイル名一括変換ツール
複数ファイルのファイル名を一括で変換できます。

変換方法

変換方法出力例説明
連番file_001.txtプレフィックス + 連番
日付＋連番20250904_001.txt日付 + 連番
文字列置換（指定による）指定文字列を置換
元名_連番original_001.txt元ファイル名 + 連番
元名_日付original_20250904.txt元ファイル名 + 日付

使い方

  1. 「ファイルを複数選択」からリネームしたいファイルを選択
  2. 変換方法を選択
  3. 文字列置換の場合は、置換元・置換先を入力
  4. プレフィックス（接頭語）を必要に応じて入力
  5. 「変換＆ダウンロード」ボタンをクリック
  6. リネームされたファイルがZIP形式でダウンロードされます
📝 ヒント

ファイル選択後、個別にファイルを削除することも可能です。不要なファイルは「削除」ボタンで除外してください。

圧縮ファイル生成ツール
複数ファイルをZIP・TAR・TAR.GZ形式で圧縮できます。

対応形式

形式特徴用途
ZIPWindows標準対応、パスワード設定可能一般的なファイル送付
TARUnix/Linux標準、高い互換性サーバー間でのファイル転送
TAR.GZTAR + gzip圧縮、高圧縮率サイズを抑えたい場合

使い方

  1. 「ファイルを複数選択」から圧縮したいファイルを選択
  2. 圧縮形式（ZIP/TAR/TAR.GZ）を選択
  3. ZIPの場合、必要に応じてパスワードを設定
  4. 圧縮ファイル名を指定（省略可）
  5. 「圧縮＆ダウンロード」ボタンをクリック
⚠️ パスワード付きZIP

パスワードは別途安全な方法で共有してください。パスワードを忘れると解凍できません。

CSV整形・検証ツール
CSVファイルの整形、検証、列の並び替えや抽出ができます。

主な機能

  • 🔧 セルの前後空白削除 - データのクリーンアップ
  • 🔍 欠損チェック - 空欄セルの検出
  • 🔄 重複行チェック - 重複データの検出
  • 📋 列の並び替え - ドラッグ&ドロップで簡単操作
  • ✂️ 列の抽出 - 必要な列のみを選択
  • 🔍 フィルタ機能 - 条件に合致する行のみ抽出

使い方

  1. CSVファイルをアップロード
  2. プレビューでデータを確認
  3. 必要なオプション（整形・検証）を選択
  4. 列の並び替えが必要な場合はドラッグ&ドロップで操作
  5. 抽出したい列にチェックを入れる
  6. フィルタ条件を入力（必要な場合）
  7. 「操作を確定」ボタンをクリック
  8. 処理結果を確認後、「修正済みCSVをダウンロード」をクリック
📊 対応エンコーディング

UTF-8、Shift-JIS、CP932など主要な日本語エンコーディングに対応しています。

強固なパスワードを生成し、セッション中に管理できます。

パスワード設定オプション

  4. 「パスワード生成＆保存」ボタンをクリック

営業日計算ツール
指定期間の営業日数を計算し、カレンダーを生成できます。

機能

  • 📊 営業日数計算 - 指定期間の営業日数を自動計算
  • 📅 カレンダー表示 - 営業日・休日が一目でわかる
  • 📋 Excel出力 - 印刷可能なExcelカレンダー生成
  • 🏖️ 祝日対応 - 日本の祝日を自動考慮
  • ⚙️ 柔軟な設定 - 営業曜日・特別除外日の設定可能

使い方

  1. 開始日と終了日を設定
  2. 営業日とする曜日にチェックを入れる
  3. 祝日の扱いを設定（営業日とするか休日とするか）
  4. 特別除外日があれば入力（YYYY-MM-DD形式、カンマ区切り）
  5. 「営業日計算」ボタンをクリック
  6. 結果確認後、「エクセルでダウンロード」で印刷用カレンダーを取得
🗓️ 活用例

プロジェクトスケジューling、契約期限の確認、勤務日数の計算、休暇計画の立案など。

PDF Power
PDF操作の万能ツール。変換・分割・結合・圧縮・テキスト抽出が可能です。

主要機能

機能対応ファイル説明
PDF変換PNG, JPG, TXT, DOCX各種ファイルをPDFに変換
分割・結合PDFPDFページの分割や複数PDF結合
圧縮PDFファイルサイズを削減
テキスト抽出PDF文字データの抽出・検索

PDF変換の使い方

  1. 「PDF変換」タブを選択
  2. 変換したいファイル（画像・文書）を選択
  3. 「PDFに変換」ボタンをクリック
  4. 変換されたPDFがダウンロードされます

分割・結合の使い方

  1. 「分割・結合」タブを選択
  2. 操作したいPDFファイルを選択
  3. 「分割」または「結合」を選択
  4. 分割の場合：ページ範囲を指定（例：1-3, 5-7）
  5. 「実行」ボタンをクリック

圧縮の使い方

  1. 「圧縮」タブを選択
  2. 圧縮したいPDFファイルを選択
  3. 圧縮レベルを選択（軽度・標準・高・最大）
  4. 「圧縮してダウンロード」ボタンをクリック

テキスト抽出の使い方

  1. 「テキスト抽出」タブを選択
  2. テキストを抽出したいPDFを選択
  3. 検索ワードを入力（特定キーワードを検索する場合）
  4. 「テキスト抽出」ボタンをクリック
  5. 抽出されたテキストファイルがダウンロードされます
💡 圧縮レベルの選択
  • 軽度：画質重視、印刷用途
  • 標準：バランス重視、一般用途
  • 高：サイズ重視、Web用途
  • 最大：極限サイズ、保存用途

FILE POST - ファイル共有ツール
大容量ファイルを安全に共有できます。QRコード生成機能付き。

機能・制限

項目仕様備考
最大ファイルサイズ10GB大容量ファイル対応
保存期間7日間自動削除
パスワード保護対応任意設定
QRコード自動生成モバイル端末での共有に便利

使い方

  1. 共有したいファイルを選択
  2. 必要に応じてパスワードを設定
  3. 「アップロードして共有URL生成」ボタンをクリック
  4. 生成された共有URLをコピー
  5. QRコードを使ってモバイル端末と共有も可能
  6. ファイル受け取り側は共有URLにアクセス
  7. パスワードが設定されている場合は入力してダウンロード
🔒 セキュリティ注意事項
  • 共有URLは第三者に知られないよう注意してください
  • 機密ファイルは必ずパスワードを設定してください
  • パスワードは共有URL とは別の方法で伝達してください
  • ファイルは7日後に自動削除されます

車検証ツール
車検証PDFからOCRで情報を読み取り、自動的にファイル名を変更します。

対応形式

  • 📄 入力：車検証PDF（電子版）
  • 📊 設定ファイル：CSV（ID, 登録番号末尾4桁, 保管場所）
  • 📁 出力：リネーム済みPDF またはエラーログ

CSVファイル形式

ID,登録番号末尾4桁,保管場所
001,1234,東京都
002,5678,大阪府
003,9012,愛知県

使い方

  1. 車検証のPDFファイルを選択（複数選択可能）
  2. 設定ファイル（CSV）をアップロード
  3. OCRプリセットを選択（新車検証 or 旧車検証）
  4. 「実行＆ダウンロード」ボタンをクリック
  5. 処理結果に応じてファイルまたはZIPがダウンロードされます

出力ファイル名形式

車検満了日_ID_保管場所_登録番号.pdf

例： 20270315_001_東京都_品川500あ1234.pdf
⚠️ 使用上の注意
  • 電子車検証PDFのみ対応（スキャン画像は非対応）
  • 1ページ目のみ処理されます
  • OCR精度により読み取りエラーが発生する場合があります
  • 失敗時はエラーログファイルがダウンロードされます

❓ よくある質問（Q&A）

ログインができません ▼
A: 以下を確認してください：
  • ユーザーIDとパスワードが正しく入力されているか
  • 大文字・小文字が区別されているため、正確に入力
  • 不明な場合は管理者にお問い合わせください
ファイルのアップロードができません ▼
A: 以下を確認してください：
  • ファイルサイズが制限以内か確認（ツールによって異なります）
  • 対応ファイル形式か確認
  • ブラウザを再読み込みして再試行
  • インターネット接続が安定しているか確認
CSVファイルが文字化けします ▼
A: 文字エンコーディングの問題です：
  • CSV保存時にUTF-8（BOM付き）を選択
  • Excel で開く場合は、「データ」→「外部データの取り込み」を使用
  • DSTT内のツールは自動で文字コードを判定します
PDFの圧縮効果が少ないです ▼
A: PDFの内容によって圧縮効果は変わります：
  • 画像が多いPDFは圧縮効果が高い
  • テキストのみのPDFは圧縮効果が限定的
  • すでに圧縮されているPDFは効果が少ない
  • 「最大圧縮」レベルを試してください
ShifterSyncで重複が検出されません ▼
A: 以下を確認してください：
  • CSVファイルのモード・年月が同じか確認
  • 人物名の表記が完全一致しているか（スペース・漢字等）
  • オプション付きエントリーは別人として扱われます
  • 最大6ファイルまでの制限があります
生成されたファイルが開けません ▼
A: ダウンロードとファイル形式を確認：
  • ダウンロードが完了するまで待機
  • ファイル拡張子が正しいか確認
  • 対応アプリケーションがインストールされているか確認
  • ウイルス対策ソフトによるブロックを確認
パスワード付きZIPが解凍できません ▼
A: パスワードとZIPファイルを確認：
  • 設定したパスワードが正確に入力されているか
  • 大文字・小文字を区別
  • 使用している解凍ソフトがAES暗号化に対応しているか
  • 7-ZipやWinRARなどの対応ソフトを使用
営業日計算の結果がおかしいです ▼
A: 設定を再確認してください：
  • 営業曜日の選択が正しいか確認
  • 祝日の扱い設定（営業日とするか休日とするか）
  • 特別除外日の入力形式（YYYY-MM-DD）
  • 期間設定が正しいか確認

Chrome、Firefox、Edge、Safari の最新版を推奨します。Internet Explorer は対応していません。

  • ShifterSyncのカレンダー編集はPC推奨

  • Safari: 開発メニュー → キャッシュを空にする

    💡 ファイル処理のコツ
    • 大容量ファイルは処理時間がかかります
    • 複数ファイル処理時は、一度に選択せず分割処理を推奨
    • ネットワーク環境により処理速度が変動します
    • エラー時はファイル形式と容量を再確認してください

    🔧 システムエラー対応

    エラーコードと対処方法

    エラー原因対処方法
    413 Payload Too Largeファイルサイズ超過ファイルサイズを削減
    500 Internal Server Errorサーバー処理エラー時間をおいて再実行
    404 Not Foundページが見つからないURLを確認、再ログイン
    403 Forbiddenアクセス権限なしログイン状態を確認

    一般的なエラー対処手順

    1. ページを再読み込み（F5）
    2. 別のブラウザで試行
    3. ログアウト→再ログイン
    4. ブラウザキャッシュをクリア
    5. 時間をおいて再実行
    6. それでも解決しない場合は管理者に連絡

    🖨️ 印刷・表示の問題

    • ShifterSyncカレンダーはPDF出力を推奨

    • Adobe Reader、Foxit Reader等の使用を推奨
    • パスワード付きPDFは対応アプリケーションで開く
