## はじめに

### DSTTとは？

DSTTは、以下のような日常業務でよく使う機能を、ブラウザ上で簡単に利用できるようにしたツール集です：

- **日付の計算**：「3ヶ月後は何日？」「2つの日付の間は何日？」
- **パスワード生成**：安全で強力なパスワードを自動生成
- **PDF編集**：PDFの結合、分割、ページ抽出など
- **CSV編集**：CSVファイルの簡単な編集や変換
- **ファイル管理**：ファイル名の一括変更や圧縮
- **業務管理**：勤務日、休暇、車両検査などの管理

### 必要なもの

- パソコン（Windows、Mac、Linuxどれでも可）
- インターネットブラウザ（Chrome、Firefox、Edge、Safariなど）
- DSTTのURL（管理者から提供されます）
- ユーザーIDとパスワード（管理者から提供されます）

## 初めての方へ - 最初の設定

### 管理者の方へ：初回セットアップ

初めてDSTTを使用する場合、以下の手順で設定を行ってください。

#### ステップ1：必要なソフトウェアの確認

Python 3.8以上がインストールされているか確認してください。

```bash
python --version
```

#### ステップ2：プロジェクトの準備

```bash
# プロジェクトフォルダに移動
cd dstt

# 必要なライブラリをインストール
pip install -r requirements.txt
```

#### ステップ3：データベースの作成

初回のみ、ユーザー情報を保存するデータベースを作成します。

```bash
python init_database.py
```

実行すると以下のようなメッセージが表示されます：
```
データベースを初期化しています...
データベースの初期化が完了しました。
create_user.py を実行して新しいユーザーを作成してください。
```

#### ステップ4：ユーザーの作成

DSTTを使用するユーザーを登録します。

```bash
python create_user.py
```

以下の情報を入力します：

1. **ユーザーID**：ログインに使用するID（例：tanaka.taro）
   - 半角英数字とドット、アンダースコアが使用可能
   - すでに存在するIDは使用できません

2. **日本語名**：画面に表示される名前（例：田中太郎）
   - 日本語で入力できます

3. **パスワード**：ログイン用のパスワード
   - 確認のため2回入力します
   - 他人に推測されにくいものを設定してください

入力例：
```
=== DSTT ユーザー追加ツール ===
🆔 ユーザーID を入力してください: tanaka.taro
👤 日本語名を入力してください（例：田中太郎）: 田中太郎
🔐 パスワードを入力してください: ********
🔐 パスワードを再入力してください: ********
✅ ユーザー「tanaka.taro」（田中太郎）を登録しました。
```

#### ステップ5：DSTTの起動

すべての設定が完了したら、DSTTを起動します。

```bash
python run.py
```

起動に成功すると、以下のようなメッセージが表示されます：
```
 * Running on http://0.0.0.0:5000
 * Restarting with stat
```

これで、ブラウザから `http://localhost:5000` にアクセスできます。

## ログインとログアウト

### ログイン方法

1. ブラウザでDSTTのURL（通常は `http://localhost:5000`）にアクセスします
2. ログイン画面が表示されます
3. **ユーザーID**と**パスワード**を入力します
4. 「ログイン」ボタンをクリックします

![ログイン画面のイメージ]
- ユーザーID欄：登録したIDを入力
- パスワード欄：登録したパスワードを入力

ログインに成功すると、ホーム画面（ツール一覧画面）が表示されます。

### ログアウト方法

1. 画面の右上にある「ログアウト」ボタンをクリックします
2. ログイン画面に戻ります

**重要**：作業が終わったら、必ずログアウトしてください。特に共用パソコンを使用している場合は重要です。

## 各ツールの使い方

ホーム画面には、利用可能なすべてのツールがカード形式で表示されています。使いたいツールのカードをクリックすると、そのツールの画面に移動します。

### 📅 日付計算ツール

**URL**: `/tools/datecalc`

日付の計算を簡単に行えるツールです。

#### できること

1. **日付の加算・減算**：指定した日時に日数や時間を足したり引いたりする
2. **日付の差分計算**：2つの日時の間隔を計算する

#### 使い方

##### 【日付の加算・減算】

「○日後」「○時間前」などを計算します。

**操作手順**：

1. 「日付の加算・減算」を選択
2. 基準となる日時を入力
   - カレンダーアイコンをクリックして日付を選択できます
   - 時刻も入力できます
3. 加算または減算する期間を入力
   - 日数：何日分か
   - 時間：何時間分か
   - 分：何分分か
4. 「加算」または「減算」を選択
5. 「計算する」ボタンをクリック

**使用例**：
- 今日から30日後の日付を知りたい
  - 基準日時：2025-11-08 09:00
  - 日数：30
  - 操作：加算
  - 結果：2025-12-08 09:00

- 締切の3日前を確認したい
  - 基準日時：2025-11-30 17:00
  - 日数：3
  - 操作：減算
  - 結果：2025-11-27 17:00

##### 【日付の差分計算】

2つの日時の間隔を計算します。

**操作手順**：

1. 「日付の差分計算」を選択
2. 1つ目の日時を入力
3. 2つ目の日時を入力
4. 「計算する」ボタンをクリック
5. 結果が「○日と○時間○分」の形式で表示されます

**使用例**：
- プロジェクトの開始日から終了日までの期間を知りたい
  - 日時1：2025-11-01 09:00
  - 日時2：2025-12-15 18:00
  - 結果：44日と9時間0分

### 🔐 パスワード生成ツール

**URL**: `/tools/password_tool`

安全で強力なパスワードを自動生成するツールです。複数のパスワードを一度に生成し、CSVファイルとしてダウンロードできます。

#### できること

1. カスタマイズ可能なパスワードの生成
2. 複数のパスワードをリスト化
3. パスワードリストをCSVファイルでダウンロード

#### 使い方

**操作手順**：

1. **サービス名を入力**
   - 例：「メールアカウント」「社内システム」など
   - 何のパスワードか分かるように記入します

2. **パスワードの長さを指定**
   - デフォルト：12文字
   - 推奨：12文字以上（セキュリティを高めるため）

3. **文字の種類を選択**（チェックボックス）
   - ✅ 大文字を含む（A-Z）
   - ✅ 数字を含む（0-9）
   - ☐ 記号を含む（!@#$%など）

   **アドバイス**：
   - 最低でも「大文字」と「数字」を含めることを推奨
   - より安全性を高めたい場合は「記号」も含める

4. **「生成」ボタンをクリック**
   - 生成されたパスワードが画面に表示されます
   - 自動的にリストに追加されます

5. **複数生成する場合**
   - 上記の手順を繰り返します
   - すべて画面上のリストに保存されます

6. **パスワードをダウンロード**
   - 「CSVダウンロード」ボタンをクリック
   - `passwords.csv`ファイルがダウンロードされます
   - Excelなどで開いて管理できます

7. **リストをクリア**
   - 「リセット」ボタンで画面上のリストを削除できます
   - **注意**：リセットすると元に戻せません

**使用例**：

社内の5つのシステム用にパスワードを一括生成する場合：

1. サービス名「メールシステム」→ 生成
2. サービス名「勤怠管理」→ 生成
3. サービス名「経費精算」→ 生成
4. サービス名「ファイルサーバー」→ 生成
5. サービス名「VPN」→ 生成
6. CSVダウンロード → すべてまとめてダウンロード

**セキュリティ上の注意**：
- 生成したパスワードは必ず安全な場所に保管してください
- ダウンロードしたCSVファイルは暗号化して保存することを推奨します
- 同じパスワードを複数のサービスで使い回さないでください

### 📄 PDF処理ツール

**URL**: `/tools/pdf_power`

PDFファイルの結合、分割、ページ抽出などの操作ができるツールです。

#### できること

1. **複数のPDFファイルを1つに結合**
2. **PDFを複数のファイルに分割**
3. **特定のページだけを抽出**
4. **ページの順序を変更**

#### 使い方

##### 【PDFファイルの結合】

複数のPDFファイルを1つにまとめます。

**操作手順**：

1. 「PDF結合」を選択
2. 「ファイルを選択」ボタンをクリック
3. 結合したいPDFファイルを選択（複数選択可）
4. アップロードされたファイルの順序を確認
   - 順序を変えたい場合は、ファイル名の横の矢印ボタンで並び替え
5. 「結合する」ボタンをクリック
6. 結合されたPDFファイルがダウンロードされます

**使用例**：
- 月報の各部署のレポート（PDF）を1つのファイルにまとめる
- 契約書の本文と添付資料（別々のPDF）を1つにする

##### 【PDFの分割】

1つのPDFファイルを複数に分割します。

**操作手順**：

1. 「PDF分割」を選択
2. 分割したいPDFファイルを選択
3. 分割方法を選択
   - **ページ数で分割**：1ページごと、2ページごとなど
   - **指定ページで分割**：3ページ目、7ページ目で分割など
4. 「分割する」ボタンをクリック
5. 分割されたPDFファイルがダウンロードされます

**使用例**：
- 100ページある資料を部署ごとに分割して配布
- スキャンした書類から必要なページだけを取り出す

##### 【ページの抽出】

PDFから特定のページだけを取り出します。

**操作手順**：

1. 「ページ抽出」を選択
2. PDFファイルを選択
3. 抽出したいページ番号を入力
   - 単一ページ：「3」
   - 複数ページ：「1,3,5」
   - ページ範囲：「1-5」
   - 組み合わせ：「1-3,5,8-10」
4. 「抽出する」ボタンをクリック
5. 抽出されたページのPDFファイルがダウンロードされます

**使用例**：
- 契約書の署名ページ（最終ページ）だけを取り出す
- プレゼン資料から重要なスライドだけを抜粋

### 📝 ファイル名変更ツール

1. 共有リンクをクリック

**セキュリティ上の注意**：
- 機密性の高いファイルは必ずパスワードを設定
- 不要になった共有リンクは削除する
- 有効期限を適切に設定する

### 🏖️ 休暇管理ツール

**URL**: `/tools/leave_mgr`

従業員の休暇申請と承認を管理するツールです。

#### できること

1. 休暇申請の提出
2. 休暇申請の承認・却下
3. 休暇残日数の確認
4. 休暇取得状況の一覧表示

#### 使い方

##### 【休暇を申請する】

**操作手順**：

1. 「新規申請」ボタンをクリック
2. 休暇情報を入力
   - 休暇種別：有給、特別休暇など
   - 開始日
   - 終了日
   - 理由（任意）
3. 「申請する」ボタンをクリック
4. 承認待ち状態になります

##### 【休暇を承認する（管理者）】

**操作手順**：

1. 「承認待ち一覧」を開く
2. 申請内容を確認
3. 「承認」または「却下」ボタンをクリック
4. 却下の場合は理由を入力
5. 申請者に通知が送られます

##### 【休暇残日数を確認する】

**操作手順**：

1. ダッシュボードに自動表示されます
   - 今年度の付与日数
   - 使用日数
   - 残日数

**使用例**：
- 夏季休暇を事前に申請
- 年末年始の休暇計画を立てる
- 有給休暇の残日数を確認

### 👤 ユーザー管理ツール

**URL**: `/tools/user_management`

**※このツールは管理者のみが使用できます**

DSTTを使用するユーザーのアカウント管理を行います。

#### できること

1. 新しいユーザーの追加
2. ユーザー情報の編集
3. ユーザーの削除
4. パスワードのリセット

#### 使い方（管理者向け）

##### 【ユーザーの追加】

**操作手順**：

1. 「新規ユーザー追加」ボタンをクリック
2. ユーザー情報を入力
   - ユーザーID
   - 日本語名
   - 初期パスワード
3. 「登録」ボタンをクリック
4. 登録完了後、ユーザーにID/パスワードを通知

##### 【パスワードのリセット】

ユーザーがパスワードを忘れた場合：

**操作手順**：

1. ユーザー一覧から該当ユーザーを選択
2. 「パスワードリセット」ボタンをクリック
3. 新しい一時パスワードが生成されます
4. ユーザーに新しいパスワードを通知
5. ユーザーは次回ログイン時にパスワード変更を推奨

### 📊 月次レポート生成ツール

**URL**: `/tools/monthly_generator`

月次の業務レポートを自動生成するツールです。

#### できること

1. 月次統計データの自動集計
2. グラフ付きレポートの生成
3. PDF/Excel形式でのエクスポート

#### 使い方

**操作手順**：

1. 対象年月を選択
2. レポートの種類を選択
   - 売上レポート
   - 勤怠レポート
   - 業務統計レポート
3. 集計条件を設定（部署、担当者など）
4. 「レポート生成」ボタンをクリック
5. レポートがプレビュー表示されます
6. 「PDFダウンロード」または「Excelダウンロード」を選択
7. レポートファイルがダウンロードされます

**使用例**：
- 月末の売上報告書を自動作成
- 各部署の勤怠状況を月次でまとめる
- 経営会議用の資料を効率的に準備

## よくある質問（FAQ）

### Q1. パスワードを忘れてしまいました

**A1**：管理者に連絡してパスワードをリセットしてもらってください。管理者は「ユーザー管理ツール」からパスワードをリセットできます。

### Q2. ファイルのアップロードに失敗します

**A2**：以下を確認してください：
- ファイルサイズが大きすぎないか（上限は管理者に確認）
- ファイル名に特殊文字（\ / : * ? " < > |）が含まれていないか
- インターネット接続が安定しているか

### Q3. ダウンロードしたファイルが開けません

**A3**：
- PDFファイル：Adobe ReaderなどのPDF閲覧ソフトで開いてください
- CSVファイル：ExcelやGoogleスプレッドシートで開いてください
- ZIPファイル：解凍ソフトで解凍してから開いてください

### Q4. 作業中にエラーが表示されました

**A4**：
1. エラーメッセージをメモまたはスクリーンショットで保存
2. ブラウザを更新（F5キー）してもう一度試す
3. それでも解決しない場合は管理者に連絡
4. エラーメッセージを伝える

### Q5. 古いデータを削除したいのですが

**A5**：各ツールに削除機能がある場合は、そこから削除できます。削除権限がない場合や一括削除が必要な場合は、管理者に相談してください。

### Q6. スマートフォンでも使えますか？

**A6**：基本的にはパソコンでの使用を想定していますが、スマートフォンのブラウザでも一部の機能は利用できます。ただし、ファイルのアップロード/ダウンロードはパソコンでの実行を推奨します。

### Q7. 複数のブラウザタブで同時に使えますか？

**A7**：使えますが、同じツールを複数のタブで開いてデータを編集すると、データの整合性が取れなくなる可能性があります。1つのツールは1つのタブで操作することを推奨します。

### Q8. ログインしたまま席を離れても大丈夫ですか？

**A8**：セキュリティ上、席を離れる際は必ずログアウトするか、パソコンをロックしてください。一定時間操作がない場合は自動的にログアウトされる設定になっている場合もあります。

## 困ったときは

### エラーが表示された場合

1. **エラーメッセージを確認**
   - エラーメッセージをよく読んで、何が問題かを確認

2. **基本的な対処法を試す**
   - ブラウザを更新（F5キーまたは更新ボタン）
   - ブラウザのキャッシュをクリア
   - 一度ログアウトして再度ログイン
   - 別のブラウザで試す

3. **それでも解決しない場合**
   - エラーメッセージのスクリーンショットを撮影
   - いつ、どの操作で発生したかをメモ
   - 管理者に連絡

### サポートが必要な場合

管理者に以下の情報を伝えるとスムーズです：

- **使用していたツール名**（例：PDFツール）
- **実行しようとした操作**（例：3つのPDFを結合しようとした）
- **エラーメッセージ**（スクリーンショットがあれば最適）
- **使用環境**（Windows/Mac、ブラウザの種類）

### 管理者への連絡方法

システム管理者の連絡先は、各組織で指定された方法で確認してください。
